# CTrace

CTrace 是一个面向 C 语言初学者的学习项目，目标是把 C 编译器的错误信息转化为更容易理解的诊断，并逐步展示程序的执行过程。

## 计划中的功能

- v0.1：分析单个 C 文件的编译错误，显示位置、原始信息和中文解释。
- v0.2：在经过安全隔离后，检测部分运行时错误。
- v0.3：以时间线等方式展示程序执行过程。

## 当前状态

项目目录和 Git 仓库已建立，功能代码尚未实现。

## 开发环境

主要在 WSL Ubuntu 24.04 中开发，使用 Python、Clang 和 GCC。前端工具将在需要时引入。

## 安全原则

v0.1 只分析编译错误，不执行用户提交的 C 程序。不可信代码的运行功能必须先设计并验证隔离措施。
